# Aşama 2 — Gerçek Personal / Corporate Architecture

**En önemli aşama.**

Mevcut:

```text
User
  +
ADMIN / USER
  +
Room
```

yapısının üzerine final mimariyi kuracağız.

Hedef:

```text
PERSONAL CONTEXT
    ↓
kendi görevleri


CORPORATE CONTEXT
    ↓
Room
    ↓
ADMIN / USER
    ↓
Corporate Tasks
    ↓
Task Requests
```

Ve:

```text
Personal ≠ Corporate
```

yalnızca frontend filtresi olmayacak.

**DB + backend authorization + task queries + room/request mantığı birlikte değişecek.**

Bu aşamada Antigravity'nin çok dosyalı değişiklik kabiliyeti özellikle işimize yarayacak.
